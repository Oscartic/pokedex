# Develop
1. clone repo 
2. run 
````
npm install
````
3. Install Nest CLI
````
npm i -g @nestjs/cli
````
4. run DB
````
docker-compose up -d 
````
5. Clone ```__.env.template__``` and rename de file like a ```__.env__```
6. feel the env variables 
7. run application with dev environment:
`````
npm run start:dev
`````
8. fell db seeds
`````
http://localhost:3000/api/v2/pokemon (only for develop)
`````
